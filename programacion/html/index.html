    🌐 HTML desde Cero

    Antes de empezar...

    Cada página web que visitas tiene una estructura que organiza textos, imágenes, enlaces y muchos otros elementos.

    HTML es el lenguaje encargado de construir esa estructura. Podríamos decir que es el esqueleto de una página web.

    No se encarga de los colores ni de las animaciones, pero sí de organizar todo lo que aparece en pantalla.

    ¿Qué aprenderás aquí?

    📌 Cómo se estructura una página web.

    📌 Qué son las etiquetas.

    📌 Cómo crear títulos y párrafos.

    📌 Cómo insertar imágenes y enlaces.

    📌 Cómo construir tablas y formularios.

    📌 Qué significa que una página sea semántica.

    ¿Por qué aprender HTML?

    Porque es la puerta de entrada al desarrollo web.

    Prácticamente cualquier persona que quiera crear páginas web termina aprendiendo HTML tarde o temprano.

    Empecemos 🌐

    Vamos a conocer las piezas básicas que forman cualquier página web moderna.

    ¿Qué es HTML?

    Cada página web que visitas está construida con HTML. Cuando abres una página y ves títulos, imágenes, enlaces o formularios, detrás de todo eso hay etiquetas HTML organizando el contenido.

    HTML no se encarga de los colores ni de las animaciones. Su trabajo es darle estructura a la página y decirle al navegador qué es cada elemento que aparece en pantalla.

    Por eso suele decirse que HTML es el esqueleto de una página web.

    Etiquetas

    HTML funciona mediante etiquetas.

    Las etiquetas son instrucciones que indican al navegador qué debe mostrar y cómo debe organizar la información. Algunas sirven para crear títulos, otras para párrafos, imágenes, enlaces o tablas.

    La mayoría de las etiquetas tienen una apertura y un cierre, aunque algunas funcionan por sí solas.

    Títulos y párrafos

    Cuando queremos organizar información, los títulos nos ayudan a separar los temas y los párrafos nos permiten desarrollar las ideas.

    Los títulos tienen diferentes niveles de importancia. El principal suele aparecer una sola vez en la página, mientras que los demás ayudan a dividir el contenido en secciones más pequeñas.

    Esto no solo mejora la apariencia de la página, sino también la experiencia de lectura para los usuarios.

    Listas

    Muchas veces necesitamos mostrar información de forma ordenada.

    Para eso existen las listas, que permiten presentar elementos uno debajo del otro sin necesidad de escribir grandes bloques de texto.

    Son muy útiles para mostrar pasos, características, recomendaciones o cualquier conjunto de elementos relacionados.

    Enlaces

    Una de las razones por las que internet funciona como una gran red es gracias a los enlaces.

    Los enlaces permiten pasar de una página a otra con un solo clic. También pueden dirigirnos a documentos, imágenes, videos o cualquier otro recurso disponible en internet.

    Prácticamente toda la navegación web se basa en ellos.

    Imágenes

    Las imágenes ayudan a complementar la información y hacen que una página resulte más atractiva.

    Además de mostrar fotografías o ilustraciones, es importante incluir descripciones que permitan entender el contenido incluso cuando la imagen no puede visualizarse correctamente.

    Tablas

    Cuando tenemos información organizada en filas y columnas, una tabla suele ser la mejor opción.

    Las tablas permiten presentar datos de forma clara y facilitan la comparación entre diferentes elementos.

    Por ejemplo, pueden utilizarse para mostrar horarios, precios, inventarios o resultados.

    Formularios

    Los formularios son los encargados de recoger información de los usuarios.

    Cada vez que inicias sesión, completas un registro o envías un mensaje desde una página web, estás utilizando un formulario.

    Gracias a ellos las páginas pueden interactuar con las personas y recibir datos para procesarlos posteriormente.

    Estructura semántica

    Antes era común construir páginas usando muchas divisiones genéricas, pero HTML5 incorporó etiquetas que describen mejor el contenido.

    Estas etiquetas ayudan a identificar qué parte corresponde al encabezado, cuál contiene la información principal y cuál pertenece al pie de página.

    Además de mantener el código más ordenado, también facilitan el trabajo de los motores de búsqueda y las herramientas de accesibilidad.
