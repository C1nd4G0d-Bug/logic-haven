## Empecemos 🔷

Comenzaremos con las bases necesarias para escribir tus primeras líneas de código y entender cómo funciona un programa en C#.

# ¿Qué es C#?

C# es un lenguaje de programación creado por Microsoft y utilizado para desarrollar aplicaciones, páginas web, videojuegos y muchas otras herramientas que usamos todos los días.

Aunque al principio puede parecer un poco más estricto que otros lenguajes, esa estructura ayuda a mantener el código ordenado y facilita el trabajo cuando los proyectos comienzan a crecer.

# Estructura de un programa

Todo programa necesita una organización para que la computadora pueda entender qué debe hacer.

En C#, el código suele dividirse en diferentes partes, cada una con una función específica. Algunas se encargan de iniciar la aplicación, otras almacenan información y otras ejecutan acciones concretas.

Comprender esta estructura desde el principio hace que sea mucho más fácil leer y escribir programas.

# Comentarios

Mientras programamos es normal olvidar por qué escribimos ciertas instrucciones o qué problema intentábamos resolver.

Los comentarios sirven precisamente para eso: dejar pequeñas notas dentro del código que solo podrán leer las personas que lo revisen.

La computadora ignora completamente estos mensajes, pero pueden ser de gran ayuda cuando regresamos a un proyecto después de mucho tiempo.

# Variables

Los programas trabajan constantemente con información que cambia.

Por ejemplo, el nombre de un usuario, una cantidad de dinero o la puntuación de un juego.

Las variables permiten guardar esos datos para utilizarlos más adelante cuando sea necesario.

# Tipos de datos

No toda la información se almacena de la misma manera.

Un número entero no se comporta igual que un texto, una fecha o un valor verdadero o falso.

Por eso C# utiliza diferentes tipos de datos para organizar mejor la información y evitar errores durante la ejecución.

# Operadores

Los operadores son herramientas que nos permiten trabajar con los datos.

Algunos sirven para realizar operaciones matemáticas, otros comparan valores y otros ayudan a tomar decisiones dentro del programa.

Son parte fundamental de prácticamente cualquier aplicación.

# Condicionales

No siempre queremos que un programa haga exactamente lo mismo.

Muchas veces necesitamos que reaccione de forma distinta dependiendo de una situación específica.

Por ejemplo, permitir el acceso a un usuario, mostrar un mensaje de error o ejecutar una acción determinada.

Las estructuras condicionales hacen posible este tipo de comportamientos.

# Bucles

Existen tareas que deben repetirse varias veces.

En lugar de escribir la misma instrucción una y otra vez, podemos utilizar bucles para automatizar el proceso.

Esto permite ahorrar tiempo y mantener el código mucho más limpio.

# Manejo de errores

Por más cuidado que tengamos, siempre existe la posibilidad de que algo salga mal.

Un usuario puede ingresar información incorrecta o un proceso puede fallar inesperadamente.

Por eso C# ofrece mecanismos para detectar errores y evitar que la aplicación se cierre de forma abrupta.

# Clases y objetos

Cuando los programas se vuelven más grandes, necesitamos una mejor forma de organizar la información.

Las clases funcionan como plantillas que describen cómo deben ser ciertos elementos dentro del programa.

A partir de ellas podemos crear objetos que tendrán características y comportamientos propios.

Este enfoque permite construir aplicaciones más ordenadas y fáciles de mantener.
