# Logic Haven

Logic Haven es un sitio de apuntes, laboratorios y recursos de estudio para temas de programación, ciberseguridad y bases de datos.

## Propósito

Este proyecto nace como un "segundo cerebro digital": un espacio para organizar conocimiento, documentar aprendizajes y compartir contenido claro, útil y práctico.

## Stack

- MkDocs
- Material for MkDocs
- Markdown
